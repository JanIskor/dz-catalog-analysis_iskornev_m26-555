## О проекте

Программа для анализа небольшого каталога фильмов.
Реализованы вычисление статистики, фильтрация и сортировка фильмов, обработка строк, работа со словарями и множествами, а также формирование итогового отчёта.

## Реализованные этапы

1. **Базовая статистика** — средний рейтинг, возраст фильмов, перевод продолжительности в часы и минуты.
2. **Условия** — классификация фильмов по рейтингу и году выпуска.
3. **Циклы** — фильтрация фильмов, поиск первого шедевра, подсчёт длинных фильмов.
4. **Строки** — нормализация названий, создание slug, форматирование информации о фильме.
5. **Сортировка** — сортировка по рейтингу и выбор топ-N фильмов.
6. **Словари** — подсчёт фильмов по жанрам, фильмография актёров, отбор фильмов с рейтингом выше среднего.
7. **Множества** — уникальные жанры, общие актёры, разность жанров двух каталогов.
8. **Генераторы** — перебор высокорейтинговых фильмов и подсчёт суммарной продолжительности.
9. **Итоговый отчёт** — сводная статистика каталога с форматированным выводом.
